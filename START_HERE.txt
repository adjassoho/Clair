┌─────────────────────────────────────────────────────────────────────────┐
│ ÉTAPE 1 : Recharger l'extension                                         │
└─────────────────────────────────────────────────────────────────────────┘

  1. Ouvrez Chrome
  2. Tapez dans la barre d'adresse : chrome://extensions/
  3. Trouvez "Teams FR Companion"
  4. Cliquez sur l'icône 🔄 (recharger)

┌─────────────────────────────────────────────────────────────────────────┐
│ ÉTAPE 2 : Ouvrir la console de debug                                    │
└─────────────────────────────────────────────────────────────────────────┘

  1. Sur la page chrome://extensions/
  2. Sous votre extension, cliquez sur : "Inspect views: offscreen.html"
  3. Une fenêtre DevTools s'ouvre
  4. Allez dans l'onglet "Console"
  5. LAISSEZ CETTE FENÊTRE OUVERTE à côté de Chrome

┌─────────────────────────────────────────────────────────────────────────┐
│ ÉTAPE 3 : Lancer une réunion Teams                                      │
└─────────────────────────────────────────────────────────────────────────┘

  1. Rejoignez votre réunion Teams dans Chrome
  2. Cliquez sur l'icône de l'extension (en haut à droite)
  3. Cliquez sur "Démarrer" (mode "Suivre le direct")
  4. PARLEZ ou attendez que quelqu'un parle

┌─────────────────────────────────────────────────────────────────────────┐
│ ÉTAPE 4 : Lire les logs qui apparaissent                                │
└─────────────────────────────────────────────────────────────────────────┘

  Dans la console DevTools, vous devriez voir en temps réel :

    [DEBUG] connectGateway appelé - mode: audio token: mtft-xxxxx...
    [DEBUG] WebSocket créé, état: 0
    [DEBUG] WebSocket ouvert, envoi message start: {...}
    [DEBUG] Message reçu du serveur: ready {...}
    [DEBUG] Gateway ready, résolution de la promesse
    [DEBUG] Premier chunk audio reçu, offset: 123 taille: 3200
    [DEBUG] Envoi audio PCM au serveur, taille: 3200
    [DEBUG] Message reçu du serveur: segment {...}
    [DEBUG] receiveSegment appelé avec: {...}
    [DEBUG] Segment publié vers le panel

  ✅ Si vous voyez TOUT ça → Le problème est dans l'affichage du panneau
  ❌ Si ça s'arrête quelque part → NOTEZ À QUELLE LIGNE

╔═══════════════════════════════════════════════════════════════════════════╗
║  QUE FAIRE ENSUITE ?                                                      ║
╚═══════════════════════════════════════════════════════════════════════════╝

  Lisez le fichier : DEBUG_SIMPLE.md

  Il contient un diagnostic complet selon ce que vous voyez :

  • Rien du tout → Extension pas démarrée
  • WebSocket ne s'ouvre pas → Serveur pas lancé
  • Pas de 'ready' → Serveur refuse la connexion
  • Pas d'audio → Capture audio échouée
  • Pas de segment → API Gemini ne répond pas
  • Segments reçus mais invisibles → Problème d'affichage
